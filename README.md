# SME Order Fulfillment & Inventory Operations Platform

A production-style SME operations platform for managing the complete workflow from customer order to inventory fulfillment and delivery.

## Technology Stack

- Frontend: React + TypeScript
- Backend: Laravel 13
- Database: PostgreSQL
- API: REST
- Authentication: Laravel Sanctum
- Testing: Pest / PHPUnit
- Containerization: Docker
- CI/CD: GitHub Actions
- Web Server: Nginx
- Cloud: AWS

## Project Goal

The system provides one centralized workflow for:

Customer Order → Stock Check → Fulfillment → Procurement → Delivery

## Development Approach

- Feature-based development
- Git branching
- Automated testing
- Code review through Pull Requests
- Dockerized environments
- Continuous Integration
- Continuous Deployment
- AWS production deployment
